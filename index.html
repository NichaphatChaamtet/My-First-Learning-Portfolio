What I Built

นี้เป็นเว็บไซต์ Learning Portfolio แบบหน้าเดียว (Single-page Website)ของฉัน ที่พัฒนาขึ้นด้วย HTML และ CSS เพื่อใช้เป็นพื้นที่แนะนำตัวและสรุปการเรียนรู้เบื้องต้น โดยเว็บไซต์นี้ประกอบด้วยส่วนต่างๆ เช่น ส่วนแนะนำตัว (About Me) ที่มีข้อมูลส่วนตัวและรูปภาพสิ่งของที่ฉันชอบ และส่วน What I Built ที่แสดงถึงสิ่งที่ฉันได้สร้างขึ้นในระหว่างการเรียนรู้
ในขณะที่เปิดเว็บไซต์นี้ที่เปิดจากเครื่องคอมพิวเตอร์ของฉันเอง (โดยผ่านการ Double click ไฟล์ index.html) มีเพียงการทำงานของทางฝั่ง Client แต่ไม่ได้มี server เกิดขึ้น

Explain

  • Client : เว็บบราวเซอร์ทำหน้าที่เป็นเหมือน Client ที่คอยอ่านโค้ด HTML และ CSS แล้วทำการRender ออกมาเป็นหน้าเว็บไซต์ให้เรามองเห็น
  • Server : การเปิดไฟล์ด้วยวิธีนี้ บราวเซอร์จะเข้าไปดึงข้อมูลจากฮาร์ดดิสก์ในเครื่องคอมพิวเตอร์ของเราโดยตรง โดยไม่ได้มีการเชื่อมต่อหรือส่งคำร้องขอ (HTTP Request) ผ่าน Internet ไปยัง Web Server เพื่อขอข้อมูล หน้าเว็บนี้จึงทำงานแบบ offline บนเครื่องส่วนตัว 100%

How I Built It

การพัฒนาเว็บไซต์ My First Learning Portfolio ชิ้นนี้เน้นการเขียนและจัดระเบียบโค้ดด้วยตนเองตั้งแต่เริ่มต้นโดยใช้เพียง HTML และ CSS ตามข้อกำหนดของรายวิชา โดยมีขั้นตอนและกระบวนการทำงานสำคัญดังนี้ :
  • การจัดระเบียบโครงสร้างไฟล์ : สร้างโฟลเดอร์หลักสำหรับโปรเจกต์ และภายในโฟลเดอร์นัน้สร้างโฟลเดอร์ย่อยสำหรับเก็บไฟล์ต่างๆขึ้นมา เช่น โฟลเดอร์สำหรับไฟล์ CSS (css) และโฟลเดอร์สำหรับไฟล์สื่อ (media) เพื่อให้การจัดการไฟล์เป็นระเบียบและง่ายต่อการจัดระเบียบ
  • การวางโครงสร้างหน้าเว็บ HTML : สร้างไฟล์ HTML หลัก (index.html) จัดวางโครงสร้างของหน้าเว็บด้วยแท็ก HTML เช่น header, main , section, article ,ul , li เพื่อให้เนื้อหามีความเป็นระเบียบและสามารถปรับแต่งได้ง่าย
  • การจัดรูปแบบและตกแต่ง (CSS) : ทำการเชื่อมโยงไฟล์ CSS เข้ากับ HTML และปรับแต่งหน้าตาเว็บไซต์ เช่น การจัดกึ่งกลาง การกำหนดระยะขอบ (Margin) และการแก้ปัญหาเฉพาะจุด เช่น การแยกคำสั่งปรับขนาดรูปภาพ ออกจากกรอบ
    เพื่อให้ภาพแสดงผลได้พอดีไม่ล้นกรอบ
  • การตรวจสอบและแก้ไข (Debugging) : ทดสอบการแสดงผลบนเบราว์เซอร์ และตรวจสอบความถูกต้องของการเชื่อมโยงไฟล์ (Relative path) โดยปรับแก้การใช้เครื่องหมายใน path ให้เป็น Forward slash (/) เสมอ เพื่อป้องกันปัญหาลิงก์เสีย (Broken link) เมื่อนำไฟล์ไปเปิดบนระบบปฏิบัติการอื่น
  • เครื่องมือและแหล่งข้อมูลที่ใช้ : ใช้โปรแกรมเขียนโค้ด (VS Code) สำหรับการเขียนและแก้ไขโค้ด HTML และ CSS, ใช้ Google Gemini สำหรับปรึกษาและค้นหาข้อมูลเกี่ยวกับการเขียนโค้ด และใช้ เว็บไซต์ W3Schools เป็นแหล่งอ้างอิงสำหรับหาฟอนต์ตัวหนังสือ

Reflection

  • ประสบการณ์และความท้าทายที่พบในการพัฒนาเว็บไซต์: การไม่รู้ว่าแท็กตัวไหนใช้ยังไงและมีหน้าที่อะไรบ้าง ทำให้ต้องค้นหาข้อมูลเพิ่มเติมเกี่ยวกับแท็ก HTML และ CSS เพื่อให้สามารถใช้งานได้อย่างถูกต้อง
  • จากการทำ A1 นี้ เข้าใจอะไรเกี่ยวกับการพัฒนาเว็บไซต์มากขึ้น : ทำให้เข้าใจความหมายและวิธีการใช้งานแท็กมากขึ้น และทำให้รู้เหตุผลของการต้องจัดไฟล์และโครงสร้างให้เป็นระเบียบ
  • สิ่งที่อยากปรับปรุงหรือพัฒนาต่อไปในอนาคต : อยากพัฒนาให้เว็บมีฟังก์ชันเยอะขึ้น มีการ input , output เพื่อถามตอบกับเจ้าของเว็บ เพื่อจะได้ฝึกการเขียนโค้ดให้ดีขึ้นด้วย
